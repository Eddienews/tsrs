# Exemplos de skills e plugins

Extensões de exemplo para começar e para copiar. Em **Extensões** no TSRS, a
seção **Exemplos** instala qualquer uma com um clique (uma cópia vai para
`extensoes/`, onde você pode editar à vontade).

| Pasta | O que é |
| --- | --- |
| `skills/escrita-clara` | Guia para textos claros em português |
| `skills/ata-de-reuniao` | Ata no mesmo formato sempre, com um modelo em arquivo |
| `skills/roteiro-video-curto` | Roteiro de Reels/Shorts, pronto para a ferramenta de vídeo curto |
| `skills/frontend-design` | Acabamento de interfaces (tipografia, superfícies, movimento), do [cult/ui](https://github.com/nolly-studio/cult-ui) (MIT); obedece ao `DESIGN.md` do projeto |
| `skills/components-build` | A especificação [components.build](https://components.build) para componentes React acessíveis e componíveis, distribuída no cult/ui (MIT) |
| `skills/taste-skill` | Direção de arte para sites, da [taste-skill](https://github.com/Leonxlnx/taste-skill) de Leonxlnx (MIT): sorteio de direção, imagens abertas com crédito e inspeção da página no navegador |
| `plugins/utilidades-livres` | Câmbio, feriados, clima e Wikipédia por APIs grátis e sem chave, uma ferramenta em JavaScript, dois comandos e um agente |

Para mandar a sua para cá, veja o [CONTRIBUTING.md](../CONTRIBUTING.md).
